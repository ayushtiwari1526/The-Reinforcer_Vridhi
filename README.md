Vridhi – AI Farming Assistant
Vridhi is an AI-powered smart farming assistant designed to help farmers make better decisions related to crop prediction, irrigation planning, fertilizer usage, and farming guidance.

It provides an intuitive dashboard with multiple intelligent tools to improve productivity and optimize resource usage.

🚀 Features

🌾 Crop Prediction

Predict suitable crops based on conditions

Helps farmers choose the best crop for higher yield

💧 Irrigation Planner
Uses weather data (temperature & humidity)

Suggests when irrigation is needed

Calculates water requirement per day

🌿 Fertilizer Intelligence System
Recommends fertilizer type and quantity

Provides NPK (Nitrogen, Phosphorus, Potassium) breakdown

Generates application schedule

📘 Farming Guide (Static Knowledge Hub)
Provides crop-wise guidance

Includes seasonal recommendations

Displays useful farming insights


🖥️ Tech Stack
